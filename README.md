
# CodePilot

An AI-powered code review and engineering assistant.

## Project Goal

Build a reliable code review tool that analyzes code changes, identifies potential bugs, explains findings with evidence, and helps developers improve code quality.

## Tech Stack

- Python
- FastAPI
- Pydantic
- pytest
- Git and GitHub

## Development Approach

This project is being built incrementally as a hands-on course in AI-assisted software engineering, prompt engineering, testing, and production practices.
